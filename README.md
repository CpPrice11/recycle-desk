# Recycle Desk

Нативне керування кошиком Windows із системного трея. Програма написана незалежно від Minibin, за дослідженням його публічних функцій і запитів користувачів.

[Завантажити останній реліз](https://github.com/CpPrice11/recycle-desk/releases/latest) · [English](README.en.md)

Версія 0.1.2 додає мініпрев’ю файлів у списку, власну іконку трея з індикатором заповнення та виправлення обробки темного заголовка таблиці. Візуальна перевірка цих змін не завершена; стан перевірок — у [replica/build-log.md](replica/build-log.md).

## Можливості

- Значок порожнього/повного кошика, кількість елементів і сумарний розмір у підказці.
- Вікно зі списком, початковим розташуванням, розміром і датою видалення.
- Пошук за назвою/шляхом; сортування натисканням заголовків.
- Відновлення вибраних елементів через Windows Shell.
- Остаточне видалення вибраного або очищення всіх дисків із підтвердженням. Типово вибране «Ні».
- Українська й English; теми Catppuccin Mocha/Latte та вибір за Windows.
- Автозапуск лише після увімкнення користувачем. Переносні налаштування.

Один клік у треї відкриває вікно. Закриття вікна або Esc залишає програму в треї й вивільняє список. Для завершення виберіть «Вийти» в меню значка або Ctrl+Q. Програма не виконує автоочищення й не надсилає телеметрію. Робота з кошиком доступна без інтернету; автооновлення використовує GitHub.

## Запуск

[Як прибрати Кошик із робочого стола: Windows 11/10, зі скриншотами](docs/hide-desktop-recycle-bin.md)

Цільова платформа: Windows 10 22H2 / Windows 11, x64. Окреме середовище .NET чи Python не потрібне.

Portable: розпакуйте ZIP у доступну для запису папку та запустіть `recycle-desk.exe`. Файл `portable.flag` задає переносний режим; налаштування зберігаються поряд у `recycle-desk.ini`.

Інсталятор: встановлює програму для поточного користувача без прав адміністратора. Налаштування лежать у `%LOCALAPPDATA%\RecycleDesk\settings.ini`. Вони зберігаються після видалення програми. Перенесення portable-папки з увімкненим автозапуском потребує повторного увімкнення автозапуску з нового шляху.

EXE та інсталятор поки не мають підпису Authenticode. Для пакетів автооновлення використовується окремий Ed25519ph-підпис, який перевіряє сама програма. Вимірювання та фактично перевірені середовища наведено в [replica/test-plan.md](replica/test-plan.md). Підтримка Windows 10 залишається цільовою до перевірки на цій ОС.

## Клавіатура

Tab / Shift+Tab: елементи керування; Ctrl+F: пошук; F5: оновити; Ctrl+A у списку: вибрати все; Delete: підтвердити остаточне видалення; Esc: сховати. Відновлення та інші кнопки мають клавіатурні мнемоніки Alt.

Відновлення використовує канонічну дію Windows: системні діалоги вирішують конфлікти назв або відсутні початкові папки. Програма перевіряє, які ідентичності залишилися в кошику, й повідомляє про неповну операцію. Вона не обходить права доступу Windows.

## Збірка

Рекомендовано: Rust stable MSVC та Windows SDK / Visual Studio Build Tools, Inno Setup для інсталятора.

```powershell
cargo test --locked
./scripts/build.ps1
$compiler = ./scripts/setup-inno.ps1
./scripts/package.ps1 -Iscc $compiler
```

Локальна GNU-збірка також можлива: GNU Rust toolchain і LLVM-MinGW `windres` у PATH або `.tools/llvm-mingw-20261020-msvcrt-x86_64/bin`. Скрипт використовує комплектний Rust linker, щоб уникнути несумісності зовнішніх linker/CRT.

```powershell
./scripts/build.ps1 -Gnu
$compiler = ./scripts/setup-inno.ps1
./scripts/package.ps1 -Target native -Iscc $compiler
```

Іконка застосунку: `resources/icons/recycle-desk-v1.ico`, створена через вбудований `imagegen` із власного опису. Прозорий растровий оригінал: `resources/icons/recycle-desk-v1.png`; `./scripts/pack-icon.ps1` відтворює ICO у дев’яти розмірах від 16 до 256 px. Готова іконка включена до проєкту, додаткові засоби обробки зображень для звичайної збірки не потрібні. Джерело, промпт і перевірки: `resources/icons/README.md`.

Контрольний живий тест: `recycle-desk.exe --self-test <абсолютний шлях до test-output>`. Він створює унікальний контрольний файл, переміщує його в кошик, відновлює й перевіряє байти, знову переміщує й остаточно видаляє лише його. Тест ніколи не очищує весь кошик; звіт записує в `integration.txt`.

Workflow перевіряє код, будує EXE, portable ZIP та інсталятор, додає SHA-256. Ручний запуск створює артефакти; тег `v*` додатково створює чернетку GitHub Release для огляду. Релізи: [CpPrice11/recycle-desk](https://github.com/CpPrice11/recycle-desk/releases).

## Автооновлення

Програма перевіряє опубліковані стабільні релізи при запуску та кожні 6 годин. Вона завантажує підписаний update ZIP у фоні й перевіряє його вбудованим відкритим ключем. Встановлення та перезапуск відбуваються, коли вікно закрито в трей, файлові операції завершені й діалогів немає. Програма очікує завершення попереднього процесу, щоб новий запуск не заблокував захист від другої копії.

Мова, тема, автозапуск і переносні налаштування зберігаються. Пункт «Автоматично оновлювати програму» в налаштуваннях вимикає перевірку та застосування; уже підготовлений пакет відкидається. Відсутність мережі, пошкоджений файл або неправильний підпис залишають поточну програму працездатною. Оновлювач не встановлює beta-версії та не виконує downgrade.

Адреса репозиторію вбудовується під час збірки із `GITHUB_REPOSITORY`; для локальної цільової збірки можна задати `RECYCLE_DESK_REPOSITORY=owner/repository`. Без адреси або ключа локальна збірка не перевіряє оновлення та показує відповідний статус у налаштуваннях.

Ключ підпису налаштовано через захищений GitHub Actions secret. Інструкція для власних збірок та результати перевірок: [replica/updater.md](replica/updater.md). Приватний ключ ніколи не додається до репозиторію чи програми.

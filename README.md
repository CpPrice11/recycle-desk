# Recycle Desk

Компактна програма для керування кошиком Windows із системного трея. Безкоштовна, з відкритим кодом.

[Завантажити](https://github.com/CpPrice11/recycle-desk/releases/latest) · [English](README.en.md)

## Можливості

- Іконка порожнього або повного кошика в треї; кількість елементів і загальний розмір у підказці.
- Список файлів із мініпрев’ю, початковим розташуванням, розміром і датою видалення.
- Пошук за назвою чи шляхом і сортування за стовпцями.
- Відновлення вибраних файлів; остаточне видалення або очищення кошика з підтвердженням.
- Українська й англійська мови, світла й темна теми та вибір теми за Windows.
- Автозапуск за бажанням, portable-режим і автоматичні оновлення.

Програма не надсилає телеметрію й не очищує кошик автоматично. Для роботи з файлами інтернет не потрібний.

## Встановлення

Цільова платформа: **Windows 10 22H2 / Windows 11, x64**. Додаткові середовища виконання встановлювати не потрібно.

- **Portable ZIP:** розпакуйте в доступну для запису папку й запустіть `recycle-desk.exe`. Залиште `portable.flag` поряд: налаштування зберігатимуться у `recycle-desk.ini`.
- **Інсталятор:** запустіть файл `*-setup.exe`. Програма встановлюється для поточного користувача без прав адміністратора. Налаштування зберігаються у `%LOCALAPPDATA%\RecycleDesk\settings.ini` і залишаються після видалення програми.

Файл `*-update.zip` призначений для автооновлення. Для першого запуску виберіть portable ZIP або інсталятор. Контрольні суми завантажень — у `SHA256SUMS.txt` поруч із файлами релізу.

## Користування

Натисніть іконку в треї, щоб відкрити вікно. Закриття вікна або **Esc** повертає програму в трей. Для завершення виберіть **«Вийти»** в меню іконки або натисніть **Ctrl+Q**.

**Ctrl+F** — пошук, **F5** — оновити список, **Ctrl+A** у списку — вибрати все, **Delete** — видалити вибране після підтвердження. Під час відновлення конфлікти назв вирішуються в системних діалогах Windows.

[Як прибрати Кошик із робочого стола — інструкція зі скриншотами](docs/hide-desktop-recycle-bin.md)

## Автооновлення

Recycle Desk перевіряє стабільні GitHub Releases при запуску й кожні шість годин. Завантажує пакет у фоні, перевіряє підпис і встановлює його, коли вікно сховано в трей, а операції з файлами та діалоги завершені. Після перезапуску налаштування зберігаються.

Автооновлення можна вимкнути в налаштуваннях. Якщо завантаження чи перевірка підпису не вдалися, поточна версія залишається на місці.

## Обмеження

EXE та інсталятор поки не мають підпису Authenticode. Пакети автооновлення мають окремий підпис, який перевіряє програма. Windows 10, повний візуальний прогін і робота з різним масштабуванням на кількох моніторах ще потребують перевірки.

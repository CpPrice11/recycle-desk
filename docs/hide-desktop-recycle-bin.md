# Як прибрати Кошик із робочого стола

[English](hide-desktop-recycle-bin.en.md) · [До README](../README.md)

Можна приховати піктограму Windows і користуватися Recycle Desk у треї. Це змінює лише видимість піктограми: файли в кошику залишаються.

Інструкцію звірено **25 жовтня 2026 року** з довідкою [Microsoft](https://support.microsoft.com/uk-ua/windows/experience/personalization/customize-the-desktop-icons-in-windows). Нижче наведено справжні скриншоти з [офіційної довідки ASUS](https://www.asus.com/support/faq/1044722/), оновленої 20 березня 2026 року. Знімки англійською; кольори й розташування елементів можуть відрізнятися у вашій збірці Windows.

## Windows 11

1. Натисніть **Win + I**, щоб відкрити **Параметри (Settings)**.
2. Перейдіть у **Персоналізація → Теми (Personalization → Themes)**.
3. У блоці **Пов’язані параметри (Related settings)** відкрийте **Параметри піктограм робочого стола (Desktop icon settings)**.

![Windows 11: у розділі Themes виділено Desktop icon settings](https://kmpic.asus.com/images/2022/03/09/48b5c4e7-f99a-46d4-8526-19d68458034e.png)

4. Зніміть прапорець **Кошик (Recycle Bin)**. Інші прапорці залиште як є.
5. Натисніть **Застосувати (Apply)**, потім **OK**.

![Windows 11: прапорець Recycle Bin угорі праворуч, кнопки Apply та OK внизу](https://kmpic.asus.com/images/2022/03/09/53f74e92-ab28-4b84-9c70-8f4594e1d2b4.png)

На знімку прапорець Recycle Bin **установлено**. Для приховування піктограми його потрібно **зняти**.

## Windows 10

1. Натисніть **Win + I** і відкрийте **Персоналізація → Теми (Personalization → Themes)**.
2. У блоці **Пов’язані параметри (Related Settings)** виберіть **Параметри піктограм робочого стола (Desktop icon settings)**. На широкому вікні посилання розташоване праворуч.

![Windows 10: посилання Desktop icon settings праворуч на сторінці Themes](https://kmpic.asus.com/images/2021/03/09/9738664a-0fe5-470d-8fbb-9027638cdc27.png)

3. Зніміть лише прапорець **Кошик (Recycle Bin)** і натисніть **Застосувати (Apply) → OK**.

![Windows 10: прапорець Recycle Bin угорі праворуч, кнопки Apply та OK внизу](https://kmpic.asus.com/images/2021/03/09/5f02161a-bcb0-4650-9091-95955f84753a.png)

Тут прапорець також показано встановленим. Зніміть його, щоб сховати Кошик.

## Як повернути піктограму

Відкрийте те саме вікно, установіть прапорець **Кошик (Recycle Bin)** і натисніть **Застосувати → OK**. Цей спосіб описано в [довідці Microsoft про відновлення піктограми](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/find-the-recycle-bin-in-windows).

Пункт робочого стола **Вигляд → Показувати піктограми робочого стола (View → Show desktop icons)** керує всіма значками, а не лише Кошиком. Для роботи з видаленими файлами через Recycle Desk натисніть його іконку в треї.

## Джерела скриншотів

Усі чотири зображення завантажуються з офіційного CDN ASUS без редагування; це не знімки ПК користувача. Вони ілюструють Windows 11 та Windows 10 у [статті ASUS №1044722](https://www.asus.com/support/faq/1044722/). Зображення та торговельні марки належать відповідним правовласникам; ліцензія MIT проєкту на них не поширюється. Якщо зовнішні зображення недоступні, відкрийте статтю-джерело; текстові кроки вище залишаються придатними.

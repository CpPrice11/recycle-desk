# Як прибрати Кошик із робочого стола

[English](hide-desktop-recycle-bin.en.md) · [До README](../README.md)

Можна приховати піктограму Windows і користуватися Recycle Desk у треї. Це змінює лише видимість піктограми: файли в кошику залишаються.

Кроки звірено **25 жовтня 2026 року** з довідкою [Microsoft](https://support.microsoft.com/uk-ua/windows/experience/personalization/customize-the-desktop-icons-in-windows). Це дата перевірки тексту, а не створення скриншотів. Знімок кінцевого діалогу взято в Microsoft; для Windows 10 залишені архівні ілюстрації ASUS 2021 року. Точного публічного знімка головних сторінок поточної збірки Windows 11 тут немає.

## Windows 11

1. Натисніть **Win + I**, щоб відкрити **Налаштування / Параметри (Settings)**.
2. Виберіть **Персоналізація (Personalization)** зліва. На цій сторінці видно рядки **Фон**, **Кольори**, **Теми** та інші налаштування.
3. Натисніть окремий рядок **Теми (Themes)** праворуч. Сторінки **Персоналізація** й **Теми** різні: вікно з рядками «Фон» і «Кольори» ще не є сторінкою «Теми».
4. На сторінці **Теми** прокрутіть до **Пов’язаних параметрів (Related settings)** і відкрийте **Параметри піктограм робочого стола (Desktop icon settings)**.
5. У новому діалозі зніміть прапорець **Кошик (Recycle Bin)**. Інші прапорці залиште як є.
6. Натисніть **Застосувати (Apply)**, потім **OK**.

![Ілюстрація Microsoft: кінцевий діалог Desktop Icon Settings із прапорцем Recycle Bin](https://support.microsoft.com/en-us/windows/media/desktop-icon-settings.png)

Ця ілюстрація показує лише кінцевий діалог, а не сучасну головну сторінку Налаштувань. Microsoft не зазначає дату її створення. На знімку прапорець Recycle Bin **установлено**; для приховування піктограми його потрібно **зняти**.

## Windows 10

Нижче архівні скриншоти ASUS 2021 року для Windows 10, не знімки поточного інтерфейсу Windows 11.

1. Натисніть **Win + I** і відкрийте **Персоналізація → Теми (Personalization → Themes)**.
2. У блоці **Пов’язані параметри (Related Settings)** виберіть **Параметри піктограм робочого стола (Desktop icon settings)**. На широкому вікні посилання розташоване праворуч.

![Windows 10: посилання Desktop icon settings праворуч на сторінці Themes](https://kmpic.asus.com/images/2021/03/09/9738664a-0fe5-470d-8fbb-9027638cdc27.png)

3. Зніміть лише прапорець **Кошик (Recycle Bin)** і натисніть **Застосувати (Apply) → OK**.

![Windows 10: прапорець Recycle Bin угорі праворуч, кнопки Apply та OK внизу](https://kmpic.asus.com/images/2021/03/09/5f02161a-bcb0-4650-9091-95955f84753a.png)

Тут прапорець також показано встановленим. Зніміть його, щоб сховати Кошик.

## Як повернути піктограму

Відкрийте те саме вікно, установіть прапорець **Кошик (Recycle Bin)** і натисніть **Застосувати → OK**. Цей спосіб описано в [довідці Microsoft про відновлення піктограми](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/find-the-recycle-bin-in-windows).

Пункт робочого стола **Вигляд → Показувати піктограми робочого стола (View → Show desktop icons)** керує всіма значками, а не лише Кошиком. Для роботи з видаленими файлами через Recycle Desk натисніть його іконку в треї.

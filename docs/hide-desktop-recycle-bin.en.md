# Hide the Recycle Bin from the desktop

[Українська](hide-desktop-recycle-bin.md) · [Back to README](../README.en.md)

Hide the Windows desktop icon and use Recycle Desk from the tray. This changes icon visibility only; files in the recycle bin remain there.

The steps were checked on **25 October 2026** against [Microsoft Support](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-desktop-icons-in-windows). This dates the text check, not the screenshots. Microsoft supplies the final-dialog illustration; the Windows 10 images are archived ASUS screenshots from 2021. This guide has no verified screenshot of the main Settings pages in the current Windows 11 build.

## Windows 11

1. Press **Win + I** to open **Settings**.
2. Select **Personalization** in the sidebar. This page lists **Background**, **Colors**, **Themes** and other options.
3. Select the **Themes** row on the right. **Personalization** and **Themes** are separate pages: the page listing Background and Colors is not the Themes page yet.
4. On **Themes**, scroll to **Related settings** and select **Desktop icon settings**.
5. Clear **Recycle Bin**, leaving the other checkboxes unchanged.
6. Select **Apply**, then **OK**.

![Microsoft illustration: final Desktop Icon Settings dialog with the Recycle Bin checkbox](https://support.microsoft.com/en-us/windows/media/desktop-icon-settings.png)

This illustrates only the final dialog, not the current Settings home page. Microsoft does not state its capture date. Recycle Bin is **checked** in the image; **clear** it to hide the icon.

## Windows 10

The following ASUS screenshots are archived Windows 10 images from 2021, not current Windows 11 Settings screenshots.

1. Press **Win + I** and open **Settings → Personalization → Themes**.
2. Under **Related Settings**, select **Desktop icon settings**. In a wide window, the link appears on the right.

![Windows 10: Desktop icon settings on the right of the Themes page](https://kmpic.asus.com/images/2021/03/09/9738664a-0fe5-470d-8fbb-9027638cdc27.png)

3. Clear only **Recycle Bin** and select **Apply → OK**.

![Windows 10: Recycle Bin checkbox at the top right, Apply and OK at the bottom](https://kmpic.asus.com/images/2021/03/09/5f02161a-bcb0-4650-9091-95955f84753a.png)

This screenshot also shows the checkbox selected. Clear it to hide the icon.

## Restore the icon

Return to the same dialog, check **Recycle Bin**, and select **Apply → OK**. See [Microsoft's restore instructions](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/find-the-recycle-bin-in-windows).

**View → Show desktop icons** controls all desktop icons, rather than just Recycle Bin. Click the Recycle Desk tray icon to manage deleted files.

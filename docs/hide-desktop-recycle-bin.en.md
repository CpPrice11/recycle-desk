# Hide the Recycle Bin from the desktop

[Українська](hide-desktop-recycle-bin.md) · [Back to README](../README.en.md)

Hide the Windows desktop icon and use Recycle Desk from the tray. This changes icon visibility only; files in the recycle bin remain there.

Checked on **25 October 2026** against [Microsoft Support](https://support.microsoft.com/en-us/windows/experience/personalization/customize-the-desktop-icons-in-windows). The screenshots below come from [ASUS Support](https://www.asus.com/support/faq/1044722/), updated 20 March 2026. Their appearance may differ from your Windows build.

## Windows 11

1. Press **Win + I** to open **Settings**.
2. Open **Personalization → Themes**.
3. Under **Related settings**, select **Desktop icon settings**.

![Windows 11: Desktop icon settings highlighted on the Themes page](https://kmpic.asus.com/images/2022/03/09/48b5c4e7-f99a-46d4-8526-19d68458034e.png)

4. Clear **Recycle Bin**, leaving the other checkboxes unchanged.
5. Select **Apply**, then **OK**.

![Windows 11: Recycle Bin checkbox at the top right, Apply and OK at the bottom](https://kmpic.asus.com/images/2022/03/09/53f74e92-ab28-4b84-9c70-8f4594e1d2b4.png)

The screenshot shows Recycle Bin **checked**. **Clear** it to hide the desktop icon.

## Windows 10

1. Press **Win + I** and open **Settings → Personalization → Themes**.
2. Under **Related Settings**, select **Desktop icon settings**. In a wide window, the link appears on the right.

![Windows 10: Desktop icon settings on the right of the Themes page](https://kmpic.asus.com/images/2021/03/09/9738664a-0fe5-470d-8fbb-9027638cdc27.png)

3. Clear only **Recycle Bin** and select **Apply → OK**.

![Windows 10: Recycle Bin checkbox at the top right, Apply and OK at the bottom](https://kmpic.asus.com/images/2021/03/09/5f02161a-bcb0-4650-9091-95955f84753a.png)

This screenshot also shows the checkbox selected. Clear it to hide the icon.

## Restore the icon

Return to the same dialog, check **Recycle Bin**, and select **Apply → OK**. See [Microsoft's restore instructions](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/find-the-recycle-bin-in-windows).

**View → Show desktop icons** controls all desktop icons, rather than just Recycle Bin. Click the Recycle Desk tray icon to manage deleted files.

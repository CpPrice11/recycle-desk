## Оригінал

S01 значок у треї (порожній/повний); S02 контекстне меню; S03 налаштування (основні/іконки/взаємодія). Зовнішні поверхні Windows: стандартний кошик, підтвердження, повідомлення.

Підтверджено: очищення всіх логічних дисків, відкриття кошика, призначення одинарного/подвійного кліку, автозапуск, власні .ico, сповіщення та вимикане підтвердження. Налаштування в реєстрі. README задає очищення одним кліком; v5.5.0 описує вимкнене початкове підтвердження.

## Власні сценарії

- F01: трей → головне вікно → підсумок і список. Порожній/завантаження/заповнений/помилка.
- F02: пошук/сортування → вибір → відновлення → результат. Конфлікт шляху вирішує Windows; помилки не приховуються.
- F03: вибір → остаточне видалення → явне підтвердження з кількістю → результат.
- F04: очистити весь кошик → окреме явне підтвердження → системна операція.
- F05: налаштування мови/теми/автозапуску → збереження; portable зберігає файл поряд з EXE.
- F06: закрити вікно → робота в треї; вихід із меню → завершення процесу.

Сутності: RecycleItem (Shell PIDL/ідентичність, назва, початковий шлях, розмір, дата видалення); Summary (кількість, байти); Settings (мова, тема, автозапуск). Немає серверної БД чи акаунтів.

Складність: M. Найскладніше — COM/Shell і часткові операції; події та великі кошики; native UI/DPI/клавіатура. Оригінальні бренд, код, тексти та ресурси не використовуються.

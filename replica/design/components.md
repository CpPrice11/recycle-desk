# Нативний інтерфейс

Робочий заголовок: Recycle Desk. Компактне вікно, мінімум 760×480 logical pixels; стандартна системна рамка, Segoe UI із системи (шрифт не постачається).

Catppuccin Mocha/Latte: https://github.com/catppuccin/palette . Ролі: base, mantle, surface0/1, text, subtext0, blue, red. Текстові кольори перевіряються відносно фону. Native high-contrast mode має пріоритет.

Системні ListView, edit і кнопки забезпечують клавіатуру, фокус та базову доступність. Видимий напис для кожної дії; пошук має видиму мітку. Ctrl+F — пошук, F5 — оновити, Delete — підтвердження видалення, Ctrl+A — вибрати все, Esc — сховати. Кнопки недоступні без вибору/під час операції. Деструктивне підтвердження початково фокусує скасування.

Значки кошика: SHGetStockIconInfo із Windows Shell (Microsoft, системний ресурс, не копіюється з Minibin). Без декоративних анімацій. Тема за системою або примусова світла/темна. Підсумок і статус лишаються видимими без заповненої таблиці.

2026-10-24: окрема власна растрова іконка застосунку згенерована через imagegen. `resources/icons/recycle-desk-v1.ico` підключено до EXE-ресурсу; PNG-оригінал і перевірка 16–128 px на Latte/Mocha збережені поруч. Значки стану кошика в треї залишаються системними, щоб зберегти порожній/повний стани.

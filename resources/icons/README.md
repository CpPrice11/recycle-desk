# Іконка Recycle Desk

- `recycle-desk-v1.png` — растровий оригінал, 1254 × 1254 px, прозорий фон.
- `recycle-desk-v1.ico` — Windows ICO з кадрами 16, 20, 24, 32, 40, 48, 64, 128 і 256 px.
- `recycle-desk-v1-preview.png` — зразки на світлому й темному фонах та в малих розмірах.

`resources/app.rc` вбудовує ICO у програму. Трей використовує цю саму іконку й додає індикатор, коли кошик містить файли.

Для повторного пакування PNG в ICO виконайте з кореня проєкту:

```powershell
./scripts/pack-icon.ps1
```

Скрипт зберігає прозорість. Готовий ICO включено до репозиторію, тому для звичайної збірки цей крок не потрібний. Векторного оригіналу немає.
